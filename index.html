Image Annotation Tool

Instructions

This tool allows you to draw rectangles on images for annotation.

  • Draw Rectangle: Click and drag on an image.
  • Zoom: Hold `Ctrl` and scroll your mouse wheel over an image.
  • Pan/Drag: Hold `Ctrl` and the left mouse button to drag the image.
  • Fullscreen: Double-click an image to enter/exit fullscreen mode.
  • Invert Colors: Press `I` while hovering over an image.
  • Contrast/Brightness: Hold the right mouse button and move the mouse up/down (brightness) or left/right (contrast).

Commands

  • P: Pause the session.
  • E (while paused): Exit and save progress.
  • → (Right Arrow): Go to the next set of images.
  • ← (Left Arrow): Go to the previous set of images.

Paused

Press 'E' to Exit and Save

Press 'P' again to Resume
